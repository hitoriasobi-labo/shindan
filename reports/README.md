# マーケティング本部 月次報告書

毎月1日に前月分の月次報告書（Excel）を作るための置き場所。形式は坂田さんの
「202609_マーケティング本部月次報告書.xlsx」に合わせている（シート「WEB・SNS数値」「トピック」）。

- `data/metrics.csv` — 月末の数値（X / Instagram / YouTube / LINE のフォロワー数、アクセス数、WEBサイト UU数）。
  1行 = 指標・年月・値・出典。2026年9月までは坂田さんの報告書から転記。
- `topics/YYYY-MM.tsv` — 「実施内容」の行（カテゴリー1、カテゴリー2、詳細 をタブ区切り）。
- `build_report.py` — 上の2つから Excel を作る。

```
python3 build_report.py 2026-10   # → out/202610_マーケティング本部月次報告書.xlsx
```

年度は4月始まり。「前月増減」「前年同月比」は今年度の行にだけ出る。Facebook は運用終了のため対象外。
